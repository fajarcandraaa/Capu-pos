# Stack Profile — backend-api (Node.js)

- Build: `npm run build`
- Test: `npm test`
- Lint: `npm run lint`
- Package manager: npm
- Folder convention: `src/modules/<feature>/{controller,service,repository}.ts`
- Naming convention: camelCase untuk fungsi/variabel, PascalCase untuk class/type
- Catatan tambahan: gunakan dependency yang sudah ada di package.json dulu sebelum
  menambah package baru; jangan floating version untuk dependency baru.
