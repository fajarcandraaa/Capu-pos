# Stack Profile — web-frontend (React)

- Build: `npm run build`
- Test: `npm run test`
- Lint: `npm run lint`
- Package manager: npm
- Folder convention: `src/features/<feature>/components|hooks|api`
- Naming convention: PascalCase untuk komponen, camelCase untuk hook (`useXxx`)
- Catatan tambahan: ikuti DESIGN.md untuk token warna/spacing/typography; jangan
  hardcode nilai visual yang sudah ada di DESIGN.md.
