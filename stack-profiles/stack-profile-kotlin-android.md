# Stack Profile — mobile-android (Kotlin)

- Build: `./gradlew assembleDebug`
- Test: `./gradlew test`
- Lint: `./gradlew ktlintCheck`
- Package manager: Gradle
- Folder convention: `app/src/main/java/.../features/<feature>` (pola MVVM)
- Naming convention: PascalCase untuk class, camelCase untuk fungsi/variabel
- Catatan tambahan: gunakan Jetpack Compose bila project sudah memakainya; jangan
  campur XML layout lama dengan Compose kecuali sudah jadi konvensi project ini.
